# Original synthetic examples

All lexical records under `input/` and derived records under `output/` are small original engineering fixtures authored for this project. LinguaTrack contributors dedicate these fixture data to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). No real upstream datasets are committed here.

They demonstrate all six language codes, a form, a sense, a relation, UD-style morphology, surface frequency, and a purely illustrative CEFR anchor. They are not corpus observations, authoritative definitions, real semantic synonym claims or calibrated proficiency labels. Fixture counts and levels must not train a production learning roadmap.

Regenerate into a new directory using `examples/synthetic.lock.json`. Changing any fixture requires updating its checksum and the committed sample outputs.
