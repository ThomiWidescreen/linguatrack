# Contributing to LinguaTrack

Keep application code in `apps/` and reusable pipeline packages in `packages/`. Application development and the lexical-data pipeline share this repository, while retaining separate dependencies and data boundaries.

For lexical data, follow the [pipeline contribution guide](packages/lexicon/CONTRIBUTING.md) and [source license policy](packages/lexicon/docs/LICENSING.md). Run its checks from `packages/lexicon/`. Do not commit raw datasets, personal learning records or credentials.
